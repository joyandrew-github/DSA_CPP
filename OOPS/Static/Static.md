//What does static mean in OOPS?
// 👉 static means “belongs to the class, not to the object.”
// - Normal variables → each object gets its own copy
// - static variables → one single copy shared by all objects
// - static methods → can be called without creating an object



🔸 What is a static variable?
// A static variable is a class-level variable.
// - Memory is allocated only once
// - Shared among all objects
// - Exists for the entire program execution



🔸 Why static variables are used?
✔ Count number of objects
✔ Share common data
✔ Save memory
✔ Maintain global-like data safely inside a class
