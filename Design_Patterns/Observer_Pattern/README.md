## Prerequisites
- **CMake** ≥ 3.16
- **Visual Studio 2022** (MSVC compiler) or **MSYS2/MinGW** (g++)
- **VS Code** with CMake Tools extension (recommended)

## Build Methods

### Method 1: VS Code + CMake Tools (Recommended)
1. Install **CMake Tools** extension in VS Code
2. Open folder `Observer_Pattern` in VS Code
3. Click **CMake: Configure** (bottom status bar) → Select **Visual Studio 2022** or **MSYS2**
4. Click **Build** (hammer icon) or press `F7`
5. Click **Run** (play icon) or press `Ctrl+F5`

### Method 2: VS Code Tasks
```bash
Ctrl+Shift+P → Tasks: Run Task → CMake: Build
```
Or use default build shortcut: `Ctrl+Shift+B`

### Method 3: Command Line (CMake + MSVC)
```bash
cd D:\Downloads\DSA\Design_Patterns\Observer_Pattern

# Configure (run once)
cmake -S . -B build

# Build
cmake --build build --config Debug

# Run
.\build\Debug\ObserverPattern.exe
```

### Method 4: Command Line (CMake + Ninja + MSVC)
```bash
cd D:\Downloads\DSA\Design_Patterns\Observer_Pattern

# Configure with Ninja generator
cmake -S . -B build -G Ninja

# Build
cmake --build build --config Debug

# Run
.\build\Debug\ObserverPattern.exe
```

## Troubleshooting

### MSYS2 g++ Issues
If using MSYS2 g++, you may encounter `cc1plus.exe` crashes. Use MSVC instead:
- CMake Tools: Select **Visual Studio 2022** as kit
- Command line: CMake auto-detects MSVC on Windows

### Missing CMakeCache.txt
```bash
# Re-configure
cmake -S . -B build
```

### Clean Build
```bash
# Remove build directory and reconfigure
rm -rf build
cmake -S . -B build
cmake --build build --config Debug
```

## VS Code Configuration

### `.vscode/tasks.json`
Provides two tasks:
- **CMake: Build** (default) - builds via CMake
- **CMake: Configure** - configures CMake project

### `.vscode/settings.json` (optional)
```json
{
    "cmake.configureOnOpen": true,
    "cmake.buildBeforeRun": true,
    "cmake.generator": "Visual Studio 17 2022"
}
```

## Design Pattern Details

This implements the **Observer Pattern**:
- **Subject**: `YouTubeChannel` - maintains list of observers, notifies on video upload
- **Observer**: `Observer` (abstract) - defines `update()` interface
- **ConcreteObserver**: `Subscriber` - receives notifications with subscriber name

### Key Files
| File | Purpose |
|------|---------|
| `include/Observer.hpp` | Abstract observer interface |
| `include/Subscriber.hpp` | Concrete observer implementation |
| `include/YouTubeChannel.hpp` | Subject with subscribe/unsubscribe/notify |
| `src/main.cpp` | Demo: create channel, subscribers, upload videos |
